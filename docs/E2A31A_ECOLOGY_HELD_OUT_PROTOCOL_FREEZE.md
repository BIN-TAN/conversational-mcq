# E2A.31a Ecology Held-Out Protocol Freeze

E2A.31a is a deterministic, no-provider freeze of the executable contract for
a possible later E2A.31 ecology canary. It does not authorize or execute
E2A.31, approve or activate the autonomous tutor candidate, or modify any
provider-facing runtime component.

## Held-out boundary

The frozen scope is the exact trophic-cascade scenario, anchor, and student
trajectory. It is not a claim that the broad ecology domain has never appeared
in prior deterministic work. E2A.28a used the generic calibration label
`ecology_population_growth`; the overlap artifact records that fact while
confirming that the predator-removal scenario, distractor claim, and causal
trajectory are not reused from E2A.24 through E2A.30.

The synthetic target asks whether removing a top predator must increase a prey
population because fewer prey are eaten. The canonical active anchor is option
D. Sound evidence must distinguish reduced direct predation from the net
food-web response, explain at least one indirect pathway, apply that mechanism
to the active anchor, and coherently reject the guaranteed-increase claim.

## Frozen contracts

The freeze includes:

- a schema-valid `TargetEvidenceContractV5` with one canonical ecology anchor,
  mechanism criteria, sound criteria, and structured contradiction criteria;
- an ecology alias contract covering direct identifiers, named aliases,
  rejection forms, bounded pronouns, and domain-specific paraphrases;
- deterministic endorsement, rejection, pronoun, and paraphrase examples that
  must resolve through `active-anchor-alias-resolution-v2`;
- an actual in-memory `StructuredAgentRequest` for production evaluator V5,
  projected into a safe compile-only artifact with its canonical request hash;
- a formal exact, normalized, token, structural, and deterministic semantic
  overlap analysis against E2A.24 through E2A.30;
- a complete artifact contract and bounded budget;
- one composite runtime identity binding the candidate, contract, request,
  overlap result, artifact contract, budget, protected source hashes, and Git
  commit;
- an explicit integrity-checked predecessor binding to E2A.30a composite
  runtime identity
  `d6b54054b19b3abcd1494f8893ced303a8bf3eb0e668f6842871435ccd98cf34`.

The compiled evaluator request must use
`production-turn-evidence-evaluator-v5`, its V5 prompt and schemas, and the
ecology alias contract. Any V1-V4 evaluator identity in that request blocks the
freeze.

## Budget

E2A.31 remains unauthorized. Its frozen maximums are:

- 29 logical generation calls;
- 87 adapter attempts;
- three adapter attempts and two transport retries per logical call;
- 900,000 input tokens;
- 70,000 output tokens;
- 970,000 total tokens;
- USD 25 when pricing metadata is available;
- provider concurrency one.

Budget and source-currentness checks remain required before every future call
and retry. This freeze grants no dispatch authority.

## Commands and artifacts

Run the deterministic verification with:

```bash
npm run eval:formative:e2a31a:smoke
npm run eval:formative:e2a31a:artifact-smoke
npm run eval:formative:e2a31a:provider-call-guard-smoke
```

Generate the no-live freeze packet with:

```bash
npm run eval:formative:e2a31a:run
npm run eval:formative:e2a31a:report
```

Artifacts are written under
`.data/e2a31a-ecology-held-out-protocol-freeze/<run_id>/` and remain ignored by
Git. They contain synthetic data only. The harness installs a network guard,
constructs no provider executor, and requires zero provider calls and zero
network requests. There is intentionally no E2A.31 live command in this phase.

## Immutable boundaries

E2A.31a reads and hash-checks, but does not modify:

- the autonomous tutor candidate;
- production evaluator V5;
- canonical anchor evidence v1;
- active-anchor resolver v2;
- parity reconciliation v1;
- profile consistency and mapping;
- bounded transport retry policy;
- the approved V2 baseline or historical evaluation artifacts.

Separate explicit authorization and a new pre-dispatch audit are required
before any E2A.31 provider call.

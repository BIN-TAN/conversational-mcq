# 新情境 AI 对话测试与系统性修正

日期：2026-09-26。审查者：本次开发助手，不是独立教师评审。

本文件保留初次 v7.6 测试记录。档案投影补测、反复误解保护和最终 v7.7 结果见 [最终跟进报告](../fresh-followup/REVIEW.md)，不要把本次初始结果当成最终版本验证。

## 本轮修改

1. 将正确识别、有提示的应用、独立迁移分开。正确解释仍可解决具体误解；不能因为套用刚讲过的例子而自动给出最强迁移标签。最强标签须有同一条当前学生证据的明确迁移观察及理由，引用必须通过校验。
2. 形成性阶段不再从答对、同意或不确定推断新的 `confidence_alignment`。保留旧值，教师页面和导出注明阶段。新的自由文本自信表达单独保留在观察与原始对话中。
3. 程序依据旧值与新值修正“值没变但被标成已更新”的机械错误。不能修补缺失引用、替换实质判断或放行错误来源；原始输出和修正记录均保留。
4. 提示词要求教学内容全部放入实际显示的消息，不再重复生成当前页面不显示的附件内容；简化解释仍须保留效度和 SEM 的测量学含义。
5. 核对研究导出时补齐前一档案的来源查询；区分有题目编号的结构化证据与没有题目关联的文字摘要。摘要条数不冒充题目数，不从文字猜测题目编号。
6. 补强失败审计：一个机械修正后的候选若又因其他问题被拒绝，后续重试成功也不能覆盖其原始输出；两个候选各自保留修正元数据。

规则和变量定义见 [FORMATIVE_INTERPRETATION_POLICY.md](../../../../FORMATIVE_INTERPRETATION_POLICY.md)。原有学生数据未重写，本次未提交、推送或部署。

## 新 AI 测试设计与结果

使用当前 host-v7.6 提示词、正式请求构造器和候选验证流程，模型为 `gpt-5.6-sol`、medium、最多 10,000 输出 tokens。六组预先编写的双轮学生输入，对应实际生成的 AI 教师回复；后一轮使用前一轮真实可见消息及校验后的档案状态。不是另一个 AI 自主扮演学生，也不是完整网站到线上数据库的测试。

- **6 种新情境、12 个对话位置、13 次真实请求。** 一次请求因实质字段变化与保留标签不一致被拒绝，随后重试成功。
- **72/72 个预先定义的机械检查通过。** 检查覆盖指定情境不得过早宣告理解、未解决误解不得关闭、暂停、迁移标签、信心不被重测、没有未显示的教学附件。这不是 100% 语义准确率。
- **3 个候选使用了机械字段标记修正。** 原始候选、修正后内容和修正审计保留在原始结果中。实质性错误仍拒绝。
- 每轮调用耗时（含该轮重试）约 4.1–42.0 秒，中位数 12.9 秒。不含网页、队列和课堂并发等待，不能与不同输入的旧测试直接比较性能。
- 收尾审计修改后，无新增调用地重放了全部 12 个接受结果和 1 个拒绝结果，并核对下一轮可见消息；接受/拒绝边界保持不变。

| 新情境 | 实际表现 | 审查判断 |
| --- | --- | --- |
| 请求例子后仅更换数字套用 | 接受当前正确解释，记录有提示的应用，未判为最强独立迁移 | 修复了上轮发现的推断过强问题 |
| 自己提出两位考生误差不同的反例 | 认可新推理，把最强判断限定在本次测量情境，并引用具体学生证据 | 有比套用例子更强的依据，但不能证明跨领域或长期保持 |
| 先非常自信地答错，再答对但没信心 | 纠正两个错误；新低信心记录为自由文本观察，不替换基线校准值 | 符合阶段区分；两类数据不能直接等同 |
| 引用同学的错误说法并明确否定，随后提问 | 区分引用、否定和疑问；没有把提问当成新的错误断言 | 该两轮范围内合理 |
| 一项纠正后又重新认同错误 | 注意到反复，重新解释两个问题，没有宣布掌握 | 合理。但首轮未形成档案更新，本例不能证明“已经从当前目录移除的误解可自动重新激活” |
| 不确定并要求休息 | 解释区间不是保证；暂停，没有从读过说明推断已学会 | 尊重学生意图，不把暂停当学习结果 |

内容核对参考 [NCME Assessment Glossary](https://ncme.org/resources/professional-learning/glossary/) 的效度、信度和测量标准误定义。实际完整对话见 [READABLE_TRANSCRIPTS.md](READABLE_TRANSCRIPTS.md)；结构化结果、请求上下文、失败候选、配置与哈希见 `live-results.json` 和 `summary.json`。

## 测试失败与修正也保留

- 新的单位测试最初假定证据目录含教师消息，但正式可用目录排除了这些消息。测试改为明确构造不合格教师引用，验证拒绝规则；不是应用把教师消息当作学生证据。
- 新增导出断言一度缺少 CSV 返回类型声明，类型检查失败；已修正。该轮在运行时编辑过测试代码，因此来源一致性检查也失败，不计作最终通过。
- 两次问题都未接触真实学生账户或数据。失败报告不得被最终成功报告替代。

## 尚不能据此确认的范围

这些是定向合成案例，共享两个测量概念的已知基线，未独立验证初始诊断准确率。强标签的引用校验不能自动证明内容在语义上真的独立；当前有效引用仍需内容审核。测试中的“反复”没有触发已经关闭并移除后的目录再激活，因此不将其列为已验证能力。原始观察与对话仍应与最新档案一起查看，档案是最后一次验证的状态而非每个新回答的即时测量。

仍需要独立教师评审、代表性学生试用，以及适合具体教学主张的学习与迁移证据。这里没有验证课堂规模的完整浏览器/AI 并发、所有 30 轮路径、所有学科、所有语言或公平性。不能据此宣布系统无 bug 或已经具备完整教学有效性。

## 复现

```sh
ASSESSMENT_QUALITY_MODEL=gpt-5.6-sol node --import tsx prisma/classroom-dialogue-canary.ts --fresh --dry-run
RUN_CLASSROOM_DIALOGUE_CANARY=true ASSESSMENT_QUALITY_MODEL=gpt-5.6-sol node --import tsx prisma/classroom-dialogue-canary.ts --fresh
node --import tsx prisma/classroom-dialogue-replay-smoke-test.ts docs/acceptance/runs/2026-09-26/fresh-dialogues/live-results.json
node --import tsx prisma/formative-interpretation-policy-smoke-test.ts
node scripts/classroom-acceptance.mjs all
```

第二条会产生付费请求，六组双轮最多 24 次（含一次语义重试/轮），没有自动传输重试。每次结果写到新目录，不覆盖历史证据。最终本地工程验证结果会单独记录，不以这些 AI 调用代替数据库或浏览器验证。

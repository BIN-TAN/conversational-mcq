# 新 AI 回复复测与系统性修正：最终记录

日期：2026-09-26。审查者为本次开发助手，尚无独立教师评审。
本轮只在本地修改和验证；未 commit、push 或部署，未改动真实学生记录。

## 修正了什么

| 问题 | 系统性处理 |
| --- | --- |
| 套用刚讲过的例子容易被判为最强迁移能力 | 区分认同、正确解释、有提示的应用与独立迁移；强标签必须有当前学生证据及明确迁移观察，仍需人工判断其语义是否成立 |
| 答对后把原来的信心解释悄悄当成新测量 | 形成性对话保留原 `confidence_alignment`；教师页面、档案及导出注明来源阶段；新的自由文本信心另记观察 |
| 没变的字段标成更新，造成不必要的拒绝 | 只修正机械性的字段标记，原值、引用、理由均不变；原始输出和修正前后哈希保留；实质性矛盾仍拒绝 |
| 一部分教学文字生成在页面不显示的附件中 | 要求教学内容全部进入可见消息，不重复生成未显示附件；模拟程序也只把真实可见消息带入下一轮 |
| 研究导出把文字摘要当作可关联的题目证据 | 增加证据格式标识；没有题目 ID 的摘要不伪造题目关联；计数明确是记录条数，不一定是题目数 |
| 档案转换导出缺少前一档案的来源信息 | 查询并导出前后档案各自的源调用和信心阶段，避免错误地显示来源不明 |
| 已关闭误解又出现，但不在当前目录里 | v7.7 增加 `uncatalogued_misconception` 证据观察和教师复核保护；可以继续教学或暂停，若此问题仍存在而要更新档案，不允许给出全部掌握/最强迁移结论 |

最后一项是安全保护，不是完整的自动误解目录重开。系统不凭文本猜测或新造正式 claim ID；反复错误及当前证据保留在观察、档案理由、注意事项和后续建议中。因此正式 claim 数量为 0 也不一定意味着没有新发现或反复出现的问题。

规则及变量定义：[FORMATIVE_INTERPRETATION_POLICY.md](../../../../FORMATIVE_INTERPRETATION_POLICY.md)、[DATA_LOGGING_SPEC.md](../../../../DATA_LOGGING_SPEC.md)。

## 新的真实 AI 测试

学生输入为预先编写的合成场景，教师回复来自真实模型请求，不是人工编造。使用正式请求构造器、当前证据校验和有界重试；后一轮带入实际前一轮可见回复和档案。没有用另一个 AI 自主扮演真实学生。

模型 `gpt-5.6-sol`，medium，最多 10,000 输出 tokens。最终提示词为 `formative-conversation-host-v7.7`。

| 最终情境 | 观察到的结果 |
| --- | --- |
| 要求解释，随后仅替换例子中的数字 | 认可正确应用，但没有给出最强独立迁移标签 |
| 提出两位考生的误差反例，并联系新用途 | 引用具体推理，给出较强判断，同时限定在本次概念和情境；不能据此证明长期保持或跨学科迁移 |
| 非常自信地答错，随后答对但没有信心 | 区分推理是否正确与主观信心；旧信心解释未被覆盖，新表达保留在观察中 |
| 引用同学的错误观点并否定，随后提问 | 没把引用、否定或疑问直接当作新的错误认同；没有把教师刚给的解释当成学生证据 |
| 先纠正一项，随后再次认同错误 | 识别反复，并继续处理两个问题，没有过早宣告掌握 |
| 仍然不懂并明确要求休息 | 暂停，不强迫新题，不因读过说明就判定理解，也不据此判为不投入 |
| 正式关闭一项误解后，又认同它，同时纠正另一项并要求结束 | 保留 SEM 的改进，记录重新出现的信度/效度错误，引用当前回答并建议教师复核；尊重停止意图，没有宣布全部理解 |

最终六组双轮加一组专项收尾，共 **13 个接受的 AI 回复、15 次实际请求、80/80 项预设机械检查通过**。两个候选因“字段值变了但标记为保留”被拒绝，分别重试一次后接受。没有为提高通过率放宽规则；失败候选仍保留。

这些检查是条件性合同/行为检查，不是 80 个独立准确率样本，更不是语义准确率或学习成效指标。最终调用延迟（含该轮重试）约 5.7–53.3 秒，中位数 15.1 秒；不含真实网页、队列或课堂并发等待。

最终原始数据、完整对话和配置见 [fresh-dialogues-final](../fresh-dialogues-final/READABLE_TRANSCRIPTS.md)。专项收尾原始结果见 [recurrence-closure-after-safeguard.json](recurrence-closure-after-safeguard.json)。

专项收尾实际回复承认 SEM 的正确解释，指出“即使完全可靠也不自动证明所有用途有效”，并说明剩余问题宜与教师讨论。档案为 `teacher_assistance_recommended`，理由为 `uncatalogued_misconception_requires_review`；生命周期为 `pause`。观察、理由和下一步证据建议都保留了该问题。

## 先前结果和失败未被覆盖

本轮整个调查共 31 次真实请求，不把重复测试算成新的独立情境：

- 初次 v7.6 六组双轮：13 次请求，含 1 次语义重试；原始文件在 `../fresh-dialogues/`。
- 模拟程序对齐正式档案保存方式后重跑受影响的两轮：2 次；原输出和修正后结果在 `../fresh-dialogues-verified/`。
- 使用实际已关闭 claim 的档案做首次反复探测：1 次，记录在 `recurrence-before-safeguard.json`。AI 回复识别了错误，但暴露了活跃目录不是完整历史目录的边界。
- v7.7 新增教师复核保护后的收尾专项：2 次，含 1 次语义重试。
- v7.7 最终六组双轮：13 次，含 1 次语义重试。

模拟程序曾漏带正式档案中的证据限制、后续证据建议，并使用了不完全一致的证据截止位置。本轮已对齐正式保存逻辑并重跑相关轮次；这是测试程序问题，不是对旧学生数据的修补。

新测试最初还暴露了两个测试代码问题：对可用证据目录的教师消息假设不成立，以及新增 CSV 断言缺少类型声明。均已修正。保存了类型失败报告和日志，不能将该轮计作最终通过。

最终全量工程测试第一次因受限环境无法连接本地数据库中断，保留在 `engineering-database-inaccessible.json`；随后获准连接本地隔离数据库，完成全部测试。没有重启或修改生产数据库。

## 仍需审查的教学风险

1. 机械引用校验只能保证证据来源合格，不能保证模型对“独立推理”“迁移”“误解反复”的语义判断总正确。初始诊断准确率本轮没有重新测量。
2. 当前目录外的反复错误已增加复核保护，但尚未实现完整自动 claim 重开。不要仅用当前 claim 数量计算误解消失率，也不要把缺少该观察解读为确定没有反复。
3. 最强能力标签仍对上下文敏感。本轮独立反例有支持，但不足以证明稳定、广泛、长期迁移。用于课堂决策前需要独立教师评审和真实学生证据。
4. 学科解释仍需抽查。例如最终第一组举例用一位考生两次接近的打字分数来说明高信度迹象；这可作一致性的直观例子，但不能作为估计或证明测试信度的充分证据。本轮未把这一措辞认证为严格的测量学论证。
5. 没有穷尽 30 轮路径、多学科、多语言、公平性或课堂规模负载，也没有证明学生学习增益。不能由这些检查推断系统无 bug，或高风险教学使用的效度验证已经完成。

# E2A.30 Thermal Physics Canary

## Status

E2A.30 has one explicit authorization for one isolated live session. The live
dispatch has not yet occurred. The E2A.29a draft is superseded by the E2A.29b
re-frozen protocol because the profile update and cross-artifact consistency
runtime identity changed.

## Held-out concept

A metal block and a wood block that have remained in the same room can be at
the same temperature while the metal feels colder. The sensation reflects a
faster transfer of thermal energy away from skin, not necessarily a lower
temperature of the metal.

The active distractor claims that the metal must be at a lower temperature
because it feels colder.

## Frozen trajectory

The protocol uses six student turns and eight evidence checkpoints. It moves
from the misconception through copied wording, partial understanding, an
explicit mechanism-conclusion contradiction, clarification, independent
rejection, and immediate revision. The evaluator-created contradiction is a
checkpoint on student turn four, and the revision decision is a checkpoint on
student turn six. This preserves normal arithmetic of 17 logical calls.

## Retry and tracing boundary

The authorized E2A.30 execution must use:

- `provider-failure-taxonomy-v1`;
- `bounded-provider-transport-retry-v1`;
- `provider-request-tracing-policy-v1`;
- `exactly-once-semantic-effects-policy-v1`.

Each logical call permits no more than three observable adapter attempts. The
canonical request, source binding, model, schema, and logical idempotency key
remain stable across transport retries. Each attempt gets a distinct adapter
attempt ID and client request ID. Semantic regeneration remains separately
bounded.

## Profile consistency boundary

The re-frozen protocol requires `turn-evidence-observation-v1`,
`learning-profile-update-disposition-v1`,
`turn-evidence-cross-artifact-consistency-v2`,
`turn-evidence-profile-mapper-v6`, and
`pre-tutor-profile-finalization-v3`. Pure non-conceptual turns cannot erase or
conflict with retained conceptual profiles. Mixed-intent turns retain
conceptual evidence before the immediate redirect. Unsupported understanding
claims cannot become sound without observable evidence.

Transport retry behavior is tested with a deterministic, no-network HTTP 520
then success fault injection before dispatch. The live trajectory does not
intentionally induce a provider failure.
